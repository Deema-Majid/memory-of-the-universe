# ذاكرة الكون 🌌

لعبة فيزياء ثنائية الأبعاد (2D) تعمل في المتصفح، من تصميم **ديما بنت ماجد المعارك** ضمن برنامج «الجيل التقني» – موهبة.

الروبوت **ذرّة** يستعيد قوانين الفيزياء المتناثرة في أربعة عوالم، وفي كل مرحلة تلعبين الحلقة نفسها: **قِسي ← استنتجي ← تصرّفي**.

| العالم | القانون |
|---|---|
| ١. الثِقل | القوة والتسارع: F = m × a |
| ٢. المرايا | انعكاس الضوء: زاوية السقوط = زاوية الانعكاس |
| ٣. المقلاع | الجاذبية والمدارات: الانحراف يتناسب مع M ÷ v² |
| ٤. الذاكرة | كل القوانين معًا (اختاري القانون المناسب لكل مهمة) |

## القواعد
- كل مرحلة تبدأ بـ ١٠ وحدات طاقة.
- الاستنتاج الخاطئ ‎−٢‎، والمحاولة الفاشلة ‎−١‎، وتجميع بطارية من المشهد ‎+٣‎ (بالضغط عليها).
- النجوم: ٣ نجوم إن بقي ٦ أو أكثر، ونجمتان إن بقي من ٣ إلى ٥، ونجمة واحدة غير ذلك.
- بعد خسارتين في المرحلة يصبح التلميح مجانيًا.
- القيم المخفية (كتلة الصندوق، كتلة الكوكب، مواضع المرايا) تتغيّر في كل مرة، فلا يمكن حفظ الحل.

## التشغيل
لا يحتاج أي تثبيت: افتحي `index.html` في المتصفح، أو شغّلي خادمًا محليًا:

```bash
python3 -m http.server 8000   # ثم افتحي http://localhost:8000
```

للتجربة السريعة بفتح كل المراحل: `index.html?unlock=1`

## النشر على GitHub Pages
1. أنشئي مستودعًا جديدًا (Public) وارفعي محتوى هذا المجلد.
2. من **Settings ← Pages** اختاري Branch: `main` والمجلد `/ (root)` ثم Save.
3. يظهر الرابط بعد دقيقة: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## الهيكل
```
index.html
css/style.css
js/util.js   الصور والصوت والحفظ
js/data.js   العوالم والمراحل والقصة
js/game.js   الفيزياء والمحرّك والرسم
js/ui.js     القوائم والواجهة والنوافذ
assets/      الصور والشخصية والخطوط والشعار
```

صُنعت بـ HTML وCSS وJavaScript فقط، بلا مكتبات خارجية.
