# ذاكرة الكون

لعبة فيزياء تعليمية بالعربية (٤ عوالم، ١٢ مرحلة). يساعد اللاعب الروبوت «ذرّة» على ترميم عوالم نسيت قوانينها.
حلقة اللعب: **قِس ← استنتج ← تصرّف**، ولكل مرحلة ١٠ وحدات طاقة.

| العالم | القانون | المهمة |
|---|---|---|
| الثِقل | القوة = الكتلة × التسارع | دفع الصندوق بالقوة المناسبة ليقف عند علامة الهدف |
| المرايا | زاوية السقوط = زاوية الانعكاس | تدوير مرايا لإيصال الشعاع إلى المستشعر |
| المقلاع | الانحناء يقلّ بزيادة السرعة | اختيار سرعة إطلاق ليمر المسبار من الحلقة |
| الذاكرة | القوانين الثلاثة معًا | مراحل تخلط المهام |

مواصفات المراحل (الكتل والزوايا والمواضع) تُولَّد عشوائيًا في كل مرة، وكلها مُختبرة آليًا على أنها قابلة للحل.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.
للتجربة السريعة بدون قفل المراحل أضف `?dev=1` إلى الرابط.

## الرفع على GitHub Pages
١. أنشئ مستودعًا جديدًا على github.com (مثلًا `dhakirat-alkawn`) بدون README.
٢. من داخل مجلد اللعبة (حيث يوجد `index.html`) شغّل في الطرفية:
```
git init
git add .
git commit -m "ذاكرة الكون"
git branch -M main
git remote add origin https://github.com/اسم-المستخدم/اسم-المستودع.git
git push -u origin main
```
٣. في المستودع: **Settings ← Pages ← Build and deployment ← Deploy from a branch ← main / (root) ← Save**.
٤. بعد دقيقة تقريبًا يعمل الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

بديل بلا طرفية: في صفحة المستودع اضغط **Add file ← Upload files** واسحب **محتويات** المجلد (لا المجلد نفسه) ثم Commit.
يجب أن يكون `index.html` في جذر المستودع.

## بنية المشروع
```
index.html          الصفحة الوحيدة
css/style.css       الواجهة
js/sim.js           فيزياء المراحل (قوة، انعكاس، جاذبية)
js/data.js          العوالم وتوليد المراحل والأسئلة
js/draw.js          الرسم على اللوحة
js/game.js          منطق اللعبة والقوائم
js/audio.js         المؤثرات الصوتية (مولّدة برمجيًا)
js/save.js          حفظ التقدّم في المتصفح
assets/             الصور والخطوط
```
يُحفظ التقدّم في `localStorage` على جهاز اللاعب فقط.
